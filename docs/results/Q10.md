# Q10. 동일 제품의 국가별 판정 차이 (Cross-country compliance gap)

> 같은 (제품, 영양소) 측정값이 US / EU / CODEX 에서 서로 다른 judgment 를 받는 케이스 식별.
> 다국가 인프라(`v_compliance_results`, 19,767 행)의 핵심 분석 결과.

## SQL

`sql/queries/Q10.sql` — 3개 부분 쿼리:
- 10-A. 영양소별 판정 차이 빈도 (any_diff, pair-wise diff)
- 10-B. "US 적합 → CODEX 위반" 패턴 (영양소별)
- 10-C. 대표 사례 리스트 (제품명 + 3국 judgment + percent_dv)

## 핵심 발견 4가지

### 1. ★ sodium 95 케이스의 "FDA 적합 → CODEX 위반" 가능성

한국 가공식품 1,308 sodium 측정 중 **95건 (7.3%)** 이 FDA(US) 기준 적합이지만 CODEX 기준 위반. 보고서 활용 시 "표준 선택이 진단 결과를 좌우하는 정량 사례" 로 활용 가능. 대부분 sodium 400 mg/100g 클러스터 — 한국 가공식품 sodium 함량의 산업적 표준점.

### 2. CODEX > US > EU 의 단조 엄격성 (sodium)

CODEX 가 US 적합을 뒤집을 수 있지만 그 반대는 0. EU 는 US 보다 살짝 느슨 (480 vs 460) → US 적합 제품 25 건이 EU 에서 추가로 moderate 로 강화 (역방향). 즉 **세 표준의 sodium 엄격도 ranking 은 한국 식품 분포에서도 일관 유지**.

### 3. 임계값 동일 영양소 (sat_fat / energy) 는 cross-country 차이 0

당연하지만 명시 가치 있음: 보고서에서 "분석 가치가 있는 cross-country 영양소는 sodium 과 sugars 두 가지" 로 명확히 framing 가능.

### 4. 3국 all-different 케이스는 어느 영양소에서도 0

3국 sodium 임계값이 다 다른데도 (400/460/480) 동일 측정값이 세 가지 다른 judgment 를 받는 케이스는 0. 이유 — sodium 차이 구간이 (380, 460) 사이에 좁아 (low ≤ 23, moderate < 92, high ≥ 92 등) "moderate → high" 한 단계만 점프. **임계값이 약간 다르다고 해서 세 단계가 모두 갈리는 일은 한국 식품 분포에서는 발생하지 않음**.

## Framing 업데이트

> 같은 한국 가공식품 1,308 sodium 측정 중 95 건이 FDA 기준 적합이지만 CODEX 기준 위반이다 (7.3%). 그중 다수가 정확히 400 mg/100g 의 함량으로, CODEX 임계값에 산업적 표준점이 일치한다. 표준 선택은 단순 임계값 차이가 아니라 한국 가공식품 sodium 분포의 클러스터 구조와 결합되어 진단 결과를 의미 있게 변화시킨다.

## Sugars surrogate 주의 사항 (재확인)

- US: added sugars 기준 (21 CFR 101.9)
- EU: total sugars 기준 (Regulation 1169/2011) — OFF 데이터와 정합
- CODEX: free sugars 기준 (WHO Sugars Guideline 2015) — added + 천연
- 본 분석의 sugars 결과 중 EU 결과만 정의 정합이고, US / CODEX 는 total 을 surrogate 로 사용한 상한 추정. 보고서 작성 시 명시 필수.
