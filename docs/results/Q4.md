# Q4 — 카테고리 내 영양소 함량 순위 (RANK 윈도우 함수)

**목적**: 각 카테고리에서 영양소별 함량 상위 5개 제품을 추출. Other 제외 (분류 불가군은 진정한 카테고리 비교 의미가 없음).

## SQL

[Q4.sql](../../sql/queries/Q4.sql)

```sql
RANK() OVER (PARTITION BY category, nutrient_code
             ORDER BY value_per_100g DESC)
```

5 카테고리 × 4 영양소 = 20 그룹, 각 그룹 top 5 (동점 RANK 포함 시 103 행).

## 해석

- **Sweets · Dairy 의 포화지방 극단치**가 두드러짐 — 초콜릿 트러플 200 %DV, 버터 297 %DV. 라벨 도입 시 'High in Saturated Fat' 경고가 일관되게 적용되어야 함.
- **Meals 의 sodium 극단치**: 간장·소스류가 일반 식품 단위 (100g) 환산 시 400 %DV 까지. 100g 기준 비교의 한계가 드러나는 케이스 — 실제 1회 섭취량(serving) 기준 환산이 필요한 향후 개선점.
- **카테고리 매핑 오류 발견**: Beverages 의 sodium top 5 에 "Seasoned Deodeok Roots" / "Gochujang" / "AnSungTangMyun Noodle" / "Premium Sesame Oil" 등 음료가 아닌 제품이 포함. Dairy 의 sodium top 1 "Cheese pork cutlet" 역시 'cheese' 키워드 매칭의 부작용.
  - Week 2 에서 인정한 product_name 키워드 매칭 (tier 4) 의 정확도 한계가 정성적으로 확인됨
  - 보고서 한계점 (limitations) 섹션에 정량 사례로 활용 가능
