# Q3 — CTE 다단계 진단 (제품별 위험도 분포)

**목적**: 보고서 4.6절의 다단계 CTE 구조 (영양소 판정 → 제품 집계 → 위험도 분류) 를 SQL 로 직접 구현하고, 진단된 제품의 위험도 분포를 확인.

## SQL

[Q3.sql](../../sql/queries/Q3.sql)

3-step CTE:
1. `violation_check` — (제품, 영양소) 단위 percent_dv 판정
2. `risk_summary` — 제품별 high / moderate / low 카운트
3. 최종 SELECT — `high_count >= 2 → high`, `high_count = 1 OR moderate_count >= 2 → medium`, 그 외 → `low`

## 결과

| risk_level | product_n | share_pct |
|---|---:|---:|
| medium | 990 | **46.54 %** |
| low | 598 | 28.11 % |
| high | 539 | 25.34 % |

(분모: 진단된 제품 2,127건 = 전체 2,493건 - undiagnosed 366건)

## 해석

- **medium 46.5 %** — 진단된 제품의 약 절반이 한 영양소 high 또는 두 영양소 moderate. 다수 한국 가공식품이 "단일 위험요소"를 가짐.
- **high 25.3 % (= 539 제품)** — 두 개 이상 영양소가 DV 20% 이상. 약 1/4 의 한국 식품이 다중 위험. 절대 수치(539)는 의외로 큼.
- **low 28.1 %** — 4개 영양소 모두에서 DV 5% 미만 또는 한 개만 moderate. "안전" 후보지만 카테고리·표본 편향 가능.
- Undiagnosed 366건 (전체의 14.7%, Q7 참조) 은 본 CTE 의 GROUP BY 에 포함되지 않음 — 위양성 적합 회피를 위해 의도된 누락.

## 보고서 활용

이 CTE 패턴은 4.6절 발표의 "다단계 룰 적용" 예시로 사용 가능. 단일 SQL 안에서:
1. 표준 기준 적용 (nutrient_limits)
2. 영양소 단위 판정 (CASE)
3. 제품 단위 집계 (FILTER + COUNT)
4. 종합 위험도 분류

가 모두 표현되어 룰 엔진의 핵심 로직을 SQL 하나로 시연.
