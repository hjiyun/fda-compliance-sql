# 한국 식품 다국가 라벨링 사전 점검 도구 (Streamlit MVP)

표준학개론 2차 프로젝트의 SQL 룰 엔진을 Streamlit 으로 포팅한 **실무 활용 사례** 입니다.
영양 성분 4 종(나트륨 · 당류 · 포화지방 · 에너지)을 100 g 기준으로 입력하면
**미국 FDA · 유럽 EU · 국제 CODEX** 3 국의 라벨 표시 의무를 실시간 판정합니다.

본 연구 보고서 5.4.3 절(셋째 항목)에서 제안한 *수출 전 사전 점검 도구* 의 구현이며,
판정 기준값은 `nutrient_limits` 테이블(3 국 × 4 영양소 = 12 행)을 코드에 임베드하여
PostgreSQL 의존성 없이 단독 실행됩니다(Streamlit Cloud 호스팅 시 비용 0).

## 실행

```bash
pip install -r requirements_app.txt
streamlit run app.py
```

기본 주소는 http://localhost:8501 입니다. (현재 로컬 실행 전용 — 호스팅 미진행)

## 기능

1. **영양 성분 입력** — 나트륨(mg) · 당류(g) · 포화지방(g) · 에너지(kcal), 모두 100 g 기준
2. **3 국 라벨 부담 판정** — `safe` / `single_warning` / `multiple_warning` 카드
3. **영양소 × 국가 진단 표** — 영양소별 판정 · % DV · 국가별 임계값
4. **국가별 % Daily Value 차트** — Plotly 막대그래프 + 20 % / 5 % DV 기준선
5. **권장 조치** — high 판정 영양소의 임계값 초과분(현재값 − 임계값) 안내

판정 기준은 21 CFR 101.13 의 5 % / 20 % DV 기준(모든 국가 공통)이며,
임계값(daily value)만 국가별로 다릅니다. high 판정 영양소 개수로 라벨 부담 수준이 결정됩니다
(0 개 = safe, 1 개 = single_warning, 2 개 이상 = multiple_warning — 보고서 4.4 절 정의).

## 한계

- **100 g 기준 통일** — FDA 의 공식 RACC(1 회 제공량) 기반 표시 자격과 정확히 일치하지 않는
  surrogate 지표입니다(보고서 5.3.3 절).
- **영양소 4 종 한정** — 나트륨 · 당류 · 포화지방 · 에너지만 평가하며, 트랜스지방 · 콜레스테롤 등은 제외됩니다.
- **단순 권장** — 권장 감축량은 *현재값 − 임계값* 의 단순 차이이며, 가중 위험 점수
  (보고서 5.4.1 절 Level 2)는 향후 과제입니다.
